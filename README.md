# 旅行乌鸦 v0.1.0

面向 SillyTavern 1.19.0（06bde939f）的独立前端扩展。手机、桌面均可用，不依赖酒馆助手，不需要服务器插件或额外 API 密钥。

## 安装

解压 ZIP，将其中的整个 `travel-raven` 文件夹放到**运行酒馆的设备**上的：

```text
SillyTavern/public/scripts/extensions/third-party/travel-raven/
```

确认 `manifest.json` 直接位于该目录，避免多套一层文件夹。刷新酒馆页面；选择一个角色进入单人聊天，右侧会出现鸟窝。如果没出现，进入扩展设置里的「旅行乌鸦」，打开「显示悬浮鸟窝」，或按「打开鸟窝 / 找回位置」。

手机浏览器访问电脑或云服务器上的酒馆时，文件应放在电脑或云服务器；Android Termux 本机运行酒馆时，放在 Termux 中的 SillyTavern 目录。首次手动部署后若素材未更新，清除该站点缓存或强制刷新。

酒馆的「通过 URL 安装扩展」需要 Git 仓库地址，不能粘贴 ZIP。发布这个仓库到 GitHub 后，在酒馆「扩展 → 安装扩展」中粘贴该仓库的 HTTPS 地址。云端托管服务若不允许访问文件，也可采用该方法；公开仓库最方便安装，私有仓库需要运行酒馆的设备具备仓库访问权限。

本地仓库默认分支为 `main`。`manifest.json` 位于仓库根目录，发布时请直接上传当前目录内的文件，不要再套一层 `travel-raven` 文件夹。GitHub Actions 会自动执行已有逻辑测试和入口语法检查。

## 怎么玩

- 小鸟窝可拖动；点一下打开面板。在家有乌鸦，出门显示空窝。
- 「鸟窝」查看状态，喂食、抚摸、准备行囊。每轮每种互动一次。
- 完成一个用户发言及角色回复，推进一轮。流式回复以完成事件为准；同轮重生成、切换回复、续写不重复推进。开场白、后台生成和用户消息本身不推进。不使用现实时间，不在线不会饿死。
- 至少在家两轮才可能出门。远行欲影响出发概率与旅行长度；每趟约 3–7 轮，中途寄信，回家带土产。饱腹太低时留在家，喂食后可再出门。
- 「明信片」保存旅行小记，可按「用角色口吻重写」额外调用当前模型一次。默认明信片使用当地风景的小插画与文字；没有为每次旅行自动生成新图片。
- 「礼物」收藏回家带来的小物。
- 「人设」首次从角色卡描述、性格、场景、示例对话作关键词初读；复杂人设建议按「用当前模型读取角色人设」，将角色转换为远行欲、亲近感、社交欲、好奇心、目的地偏好和说话风格。模型结果验证失败时保留原性格，可手动调整。
- 角色冷淡、活泼、温柔时，抚摸反应、日常动作、明信片语气不同；目的地偏好影响旅行地点权重。亲密度影响冷淡角色的抚摸反应，准备行囊提高出门概率。
- 编辑角色卡后，人设不会自动覆盖手动调整；可以重新点击读取按钮。

## 角色外形与存档

每个角色按角色卡头像文件名拥有独立的乌鸦存档；同一角色的不同聊天共享一只乌鸦。重命名角色头像文件、复制或重新导入角色卡，可能创建新乌鸦。群聊暂不显示，避免把多个 char 混到一起。

默认使用原创手绘的共用乌鸦，不会自动从角色头像生成对应外观。在「人设」可上传角色专属乌鸦**站在窝里的完整图片**（400 KB 以内 PNG/JPG/WebP，建议透明底），图片与性格一起按角色保存。角色卡没有提供给本次制作，因此此版本实现了性格化身与专属图片入口。

乌鸦状态使用酒馆扩展设置保存到服务器；轮次去重标记保存到当前聊天元数据。每只最多保留 80 张明信片、120 件礼物、60 条日志。支持导出全部乌鸦 JSON 备份与导入，导入会提示覆盖同名角色。更新扩展前建议备份；清除或重置酒馆设置可能清除存档。

模型只在点击读取人设或重写明信片时调用。使用酒馆当前连接，可能产生该服务的用量费用；读取人设沿用当前聊天上下文，因此提示会发送角色资料及酒馆已有上下文给当前服务。其他日常玩法完全本地运行，不往聊天里加消息，不修改角色卡、世界书或主聊天提示词。

## 检查与预览

本包已核对指定提交的 `SillyTavern.getContext()`、`generateQuietPrompt` 和事件接口。自动测试覆盖旅行生命周期、人设概率差异、互动限制、轮次标记、模型结果验证及长期收藏边界。浏览器预览使用模拟酒馆上下文，不能替代在你自己的手机酒馆中实测。

开发者在本目录运行 `node --test tests/*.test.js`。使用本地静态服务器打开 `demo.html` 可查看独立预览；它不会连接真实聊天模型。

## 美术

`assets/nest-atlas.png` 使用内置 ImageGen 生成，透明底，左半为空窝，右半为乌鸦站窝。原创柔和日式绘本风：铅笔轮廓、淡水彩、灰黑圆滚滚乌鸦、鼠尾草绿围巾、棕色枝条鸟窝。不是原游戏素材。

完整生成提示记录见 `ART-PROMPT.txt`。
